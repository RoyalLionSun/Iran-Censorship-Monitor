## Iran Censorship Monitor v1.2.0

v1.2 expands the monitoring architecture with a second passive routing path and establishes the security, evidence and deployment model for a future project-controlled measurement fleet.

### Routing and source depth

- Added Route Views live routing access through CAIDA BGPStream tooling.
- Prevents RIPE data accessed through BGPStream from being double-counted as an independent routing source.
- Added bounded Route Views collection and live CAIDA broker verification.
- BGP/RIS/Route Views observations remain control-plane context and are never treated as censorship votes.

### Owned measurement fleet architecture

- Added signed, short-lived Ed25519 measurement manifests.
- Scheduler may reference approved target IDs only; arbitrary hosts, URLs, ports and commands are rejected.
- Added bounded Class-A DNS, TCP, TLS and HTTPS measurement definitions.
- Added authenticated HMAC result envelopes with strict schemas.
- Added replay, rate, concurrency and memory-only queue controls.
- Added local kill/enable controls and time-bounded pseudonymous operator consent.
- Added fixed HTTPS transport with hostname verification and SPKI pinning.
- Added collection-edge admission controls that exclude source IP and forwarding headers from evidence semantics.
- Added default-deny systemd sandbox design and negative egress validation.
- Added key rotation/revocation and fail-closed rollback procedures.
- Multiple owned probes remain a single source family and cannot inflate independent evidence.

### VPN, protocol and NIN evidence policy

- Website reachability alone cannot be interpreted as WireGuard, OpenVPN, V2Ray, Outline or other transport availability.
- Protocol evidence requires controlled endpoints, neutral controls, same-probe pairing, repeated observations and analyst review.
- Even complete protocol evidence cannot automatically produce a blocked/available verdict.
- Defined prerequisites for future NIN-vs-global comparison.
- Province inference from IP, ASN or latency is prohibited.
- White-SIM vs ordinary-SIM measurement remains NO-GO under the current privacy model.

### Verification

- Added real headless Chrome/Chromium presentation verification.
- Deterministic suite expanded to **203 tests**.
- Production build, presentation gate, secret/private-key scanning and runtime smoke tests passed.
- Live public-source acceptance passed for the corresponding runtime implementation.

### Deployment boundary

This release contains the laboratory architecture for a future Stage-1 owned measurement fleet, but **does not authorize deployment of probes in Iran**.

External runtime validation, controlled endpoints, key management, rollback validation, voluntary operator consent and explicit deployment authorization remain mandatory.
