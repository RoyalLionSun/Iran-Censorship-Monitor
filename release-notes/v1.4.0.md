## Iran Censorship Monitor v1.4.0

v1.4 deepens circumvention-transport context while preserving the project's strict separation between measurement, contextual correlation and censorship attribution.

### Circumvention transport context

- Iran Tor transport observations preserve the published lower/upper estimate bounds rather than inventing exact client counts.
- Directional change is reported only when before/during estimate intervals do not overlap; overlapping or touching bounds remain indeterminate.
- Global BridgeDB requested-transport demand is exposed separately and is explicitly labelled **GLOBAL · not Iran-specific**.
- BridgeDB demand is excluded from Iran incident correlation and cannot become an Iran usage estimate or technical censorship vote.

### Incident correlation

- Tor transport observations can be aligned with Access Now #KeepItOn STOP incident windows as temporal context only.
- The comparison uses bounded pre-incident and incident-window observations and never creates a causal claim.
- A temporal match cannot become a blocking verdict, national availability status or additional independent-source vote.
- Missing paired observations remain `no_data`; partial upstream coverage remains `partial`.

### Performance-source review

- Added a reviewed Ookla Open Data contract for the official public quarterly fixed/mobile tile objects.
- No Iran aggregate is published because a defensible country-level result still requires a reviewed boundary dataset and spatial join.
- Bounding-box shortcuts, fabricated country aggregates and automatic throttling/censorship interpretation are prohibited.

### Release integrity

- Added canonical `release-notes/vX.Y.Z.md` files and a stable-version CI gate.
- Stable releases now fail CI if release notes are missing, too short, contain placeholders or omit the required verification/deployment sections.
- Added a `release: published` recovery workflow that can populate an accidentally empty GitHub Release body from the canonical notes without overwriting existing notes.
